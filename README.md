# TUSフェス Web アプリケーション

学園祭（TUSフェス）の展示・イベント・フード情報を提供する総合Webアプリケーションです。

## 📱 主な機能

### 🏠 ホーム画面
- 学園祭のハイライト画像を自動スライダーで表示
- 注目の展示やイベントを一目で確認
- 直感的なナビゲーションで各機能へアクセス

### 🔍 検索機能
展示・イベント・フード・アメニティを簡単に検索できます。

**カテゴリー別検索**
- **展示**: 研究室や学生団体の展示企画
- **フード**: 模擬店や飲食ブース
- **イベント**: ステージイベントやワークショップ
- **アメニティ**: 休憩所やトイレなどの施設情報

**高度な検索機能**
- 名前での検索
- タグによる絞り込み（家族におすすめ、学生向け、体験型など）
- 場所による絞り込み（1号館、2号館、中庭など）
- 複数条件での組み合わせ検索

### 🗺️ マップ機能
- Mapboxを使用したインタラクティブな学内マップ
- 各ブースの位置をマーカーで表示
- マーカーをタップして展示詳細を確認
- リアルタイムで現在地と目的地を把握

### ⭐ レビュー機能
- 展示やイベントに対する評価とコメント投稿
- 星評価（5段階）で視覚的に評価
- 他のユーザーのレビューを閲覧
- 人気企画の発見に役立つ

### 🎯 詳細フィルター
検索結果を細かく絞り込むための専用フィルターページ
- カテゴリー選択
- 複数タグの組み合わせ
- 場所の複数選択
- 検索条件のリセット機能

### 💝 お気に入り（パーソナルページ）
- 気になる展示やイベントをお気に入りに登録
- お気に入りリストで簡単に再アクセス
- 各企画の詳細情報（場所、時間、タグ、説明）を表示
- スケジュール管理に便利

### 🔐 認証機能
- Supabaseを使用した匿名認証
- ユーザー情報の管理
- パーソナライズされた体験の提供

## 🛠️ 技術スタック

- **フレームワーク**: Next.js 15（App Router）
- **言語**: TypeScript
- **UI**: React 18, Material-UI, Tailwind CSS
- **地図**: Mapbox GL JS
- **アニメーション**: Framer Motion, Swiper
- **認証・データベース**: Supabase
- **スタイリング**: Emotion, Tailwind CSS

## 🚀 セットアップ

### 前提条件
- Node.js 20以上
- npm または pnpm

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/tus-Web/tusfes.git
cd tusfes

# 依存関係をインストール
npm install
# または
pnpm install
```

### 開発サーバーの起動

```bash
npm run dev
# または
pnpm dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いて確認できます。

### ビルド

```bash
npm run build
npm run start
```

### リント

```bash
npm run lint
```

## 📂 プロジェクト構造

```
src/
├── app/              # Next.js App Router ページ
│   ├── page.tsx     # トップページ
│   ├── home/        # ホーム画面
│   ├── search/      # 検索ページ
│   ├── map/         # マップページ
│   ├── reviews/     # レビューページ
│   ├── filter/      # 詳細フィルターページ
│   └── personal/    # お気に入りページ
├── components/       # Reactコンポーネント
│   ├── pages/       # ページ固有コンポーネント
│   └── shared/      # 共有コンポーネント
├── lib/             # ユーティリティ関数
└── data/            # データファイル
```
